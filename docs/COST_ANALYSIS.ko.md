## Spot 인스턴스 고려사항

### 장점
1. **비용 절감**: 최대 60-70% 비용 절감
2. **동일한 성능**: On-Demand와 동일한 컴퓨팅 성능
3. **EMR 통합**: AWS EMR에서 자동 Spot 관리

### 단점
1. **중단 가능성**: AWS가 용량 필요 시 인스턴스 회수 가능
2. **가격 변동성**: Spot 가격이 시간/AZ에 따라 변동
3. **가용성 불확실성**: 특정 인스턴스 타입 불가용 가능

### 권장 사항

| 워크로드 유형 | 권장 옵션 |
|-------------|----------|
| 개발/테스트 | Spot (비용 효율적) |
| 배치 분석 | Spot (중단 시 재시작 가능) |
| 인터랙티브 분석 | On-Demand (안정성 필요) |
| 프로덕션 파이프라인 | On-Demand 또는 혼합 |

## 결론

Spot 인스턴스를 사용하면 **약 60%의 비용 절감**이 가능합니다. GWAS 벤치마크 결과, 두 클러스터 간 성능 차이는 거의 없으며 분석 결과는 완전히 동일합니다. GWAS와 같은 배치 분석 워크로드에서는 Spot 인스턴스가 매우 효과적이며, 중단 시에도 체크포인트를 통해 재시작할 수 있습니다.
